# Building a Knowledge Graph from Swami Vivekananda’s Letters with a Natural Language Query Interface Using Neo4j and Azure OpenAI
## Overview
Welcome to the Building a Knowledge Graph from Swami Vivekananda’s Letters with a Natural Language Query Interface Using Neo4j and Azure OpenAI!

This internship project features a Streamlit application that transforms Swami Vivekananda’s letters into a structured knowledge graph and provides a natural language query interface. The app uses Neo4j for managing the knowledge graph and Azure OpenAI API to translate user queries into Cypher queries and generate informative, readable responses.

## Key Features
Automated Knowledge Graph Construction: Convert Swami Vivekananda’s letters into a detailed knowledge graph that captures philosophical concepts and relationships.
Natural Language Query Interface: A chatbot that allows users to ask questions in natural language, which are then translated into Cypher queries to extract relevant information from the knowledge graph.
Readable and Informative Responses: High-quality, well-structured answers generated by the Azure OpenAI API.
Interactive Knowledge Graph Visualization: A dynamic and interactive graph visualization of the knowledge extracted from the letters.
Technologies Used
Neo4j: A graph database for storing and querying data from Swami Vivekananda’s letters.
Azure OpenAI API: Converts natural language queries into Cypher queries and provides natural language responses.
Streamlit: A framework for building the web application interface.
Selenium: A tool for visualizing the knowledge graph on the web page.
